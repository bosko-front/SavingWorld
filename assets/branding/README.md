# Saving Worlds app icon and launch mark

Source and provenance for the app icon and the launch-screen mark (Phase 19.5, DECISIONS D114 and D139). Nothing in this folder ships in the app; the app bundles only the four PNGs copied to `assets/images/`.

Status: **the owner chose concept B, the cottage close-up, with the night-blue dark icon (27 October 2026, D139).** Final approval of the icons and launch screen on the simulator is recorded in DECISIONS D139 and `docs/evidence/PHASE_19_5.md`.

## How it is made

The icon is a render of the approved Island scene (D76), not a separate drawing. `scripts/render_icon.py` opens `assets/worlds/island/source/island.blend` read-only, shows one stage, aims its own square orthographic camera (the same 57° / 0° / 45° view, lights and storybook pass as every milestone render) and renders with `swi.rig.configure_render`. It never saves the `.blend`, so the frozen milestone rig and the Island export are untouched. `scripts/icon_compose.py` (Blender's Python with numpy) then lays the transparent render on a scripted sky and writes the icon variants. Never edit the PNGs by hand: change the scripts and run them again.

| Path | What it is |
| --- | --- |
| `scripts/render_icon.py` | Renders one concept (`CONCEPTS`: stage, hidden or kept objects, square frame) and composes it |
| `scripts/icon_compose.py` | Skies, the dark and tinted variants, the launch mark, and a recompose-only entry point |
| `scripts/review_sheet.py` | Review sheet: concepts at 60, 40 and 29 pt on light, dark and tinted home screens next to plain stand-in tiles |
| `renders/concepts/` | The three concepts shown to the owner (review quality: 1024 px, 128 samples) |
| `renders/final/` | The chosen icon and mark at 2048 px, 256 samples, then scaled to 1024 px |
| `review/icon_concepts_sheet.png` | The concept sheet the owner chose from (@3x: one third of its pixel size is real size) |

### Concepts

- **A · finished_island:** the completed Island floating on its sky (stage 10, side islets hidden).
- **B · cottage_closeup (chosen):** the cottage, the big tree and the stream, cropped close (stage 10).
- **C · first_tree:** the Island with its first tree (stage 1).
- **cottage_mark:** only the cottage and the big tree, cut out, for the launch screen.

### Variants

- **Light** (`*_light.png`): the island on a day sky `#9FD2EA` → `#FBF0DC` (the app's Home sky, one step richer).
- **Dark** (`*_dark.png`): the same art at 90% brightness on a night sky `#0E1B2E` → `#2C4363`.
- **Tinted** (`*_tinted.png`): the art's brightness as grayscale on black (levels 0.10-0.95, gamma 1.1); iOS colors it with the person's tint.
- **Mark** (`*_mark.png`): transparent, cropped to the art with a 4% margin, 600 × 600 px (shown at 120 pt, so @3x has 360 px).

All three icons are 1024 × 1024, RGB without alpha, sRGB-tagged, square corners (iOS applies the mask).

## Commands

Blender 5.2.3 LTS, Cycles on the Apple M4 GPU, same as the Island workspace.

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b assets/worlds/island/source/island.blend -P assets/branding/scripts/render_icon.py -- cottage_closeup 256 assets/branding/renders/final 100
```

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b assets/worlds/island/source/island.blend -P assets/branding/scripts/render_icon.py -- cottage_mark 256 assets/branding/renders/final 100
```

Concepts: `-- <concept> 128 assets/branding/renders/concepts 50`. Recompose without rendering (after changing a sky color): `Blender -b --factory-startup -P assets/branding/scripts/icon_compose.py -- <concept> [dir]`. Review sheet: `Blender -b --factory-startup -P assets/branding/scripts/review_sheet.py -- <out.png> <dir> <concept> ...`.

Copy the finals into the app (the only files the app reads):

```bash
cp assets/branding/renders/final/cottage_closeup_light.png assets/images/icon-light.png && cp assets/branding/renders/final/cottage_closeup_dark.png assets/images/icon-dark.png && cp assets/branding/renders/final/cottage_closeup_tinted.png assets/images/icon-tinted.png && cp assets/branding/renders/final/cottage_mark_mark.png assets/images/splash-mark.png
```

`tests/unit/delivery-config.test.ts` checks the size, opacity and color tagging of the copies. A new icon is a native change: it needs a new build, and once runtime 1.0.0 is shared a new app version (docs/EAS_AND_OTA.md).
