# Island theme art (app copy)

The Island art the app bundles (Phase 09). It is an unchanged copy of the owner-approved layered export in [`assets/worlds/island/export/`](../../worlds/island/export/) (DECISIONS D76): `island_manifest.json` and the `1536/` PNGs, the one app resolution (0.75 of the 2048×1536 master canvas the manifest's coordinates use). Since Phase 10.5 it is manifest version 2: the base without clouds, three cloud layers, two water sparkle layers and one layer per tree for ambient motion (DECISIONS D91). The 2048 set and the review sheet stay in the workspace.

- Source, rebuild commands, stage-to-collection map, provenance and licensing: [`assets/worlds/island/README.md`](../../worlds/island/README.md). All geometry, materials and renders are generated by the project's own Blender scripts; no third-party assets.
- The app reads these files only through the static `require` map in `src/features/worlds/themes/island-assets.ts`; `tests/unit/world-manifest.test.ts` checks that map against this folder and that every file is byte-identical to the workspace export.
- Never edit these files. Fix art in the Blender scripts, re-run `export_layers.py`, then copy `export/island_manifest.json` and `export/1536/*.png` here again (and run the tests).
