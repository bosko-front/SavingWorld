# Garden theme art (app copy)

The Garden art the app bundles (Phase 17, Pro theme). It is an unchanged copy of the owner-approved layered export in [`assets/worlds/garden/export/`](../../worlds/garden/export/) (DECISIONS D118-D120, D123, D124): `garden_manifest.json` version 1 and the `1536/` PNGs, the one app resolution (0.75 of the 2048×1536 master canvas the manifest's coordinates use). The manifest holds the base without the two drifting clouds, two cloud layers, ten unlocks in the D119 order (51 contract layers, twelve swaying trees) and `ambientExtensions` (16 layers: water and koi from 60%, lantern glows from 70%, the greenhouse glow from 80%, butterflies from 30%, petals from 40%), which the app reads since Phase 17. The 2048 set and the review sheets stay in the workspace.

- Source, rebuild commands, layer audit, provenance and licensing: [`assets/worlds/garden/README.md`](../../worlds/garden/README.md). All geometry, materials and renders are generated by the project's own Blender scripts; no third-party assets.
- The app reads these files only through the static `require` map in `src/features/worlds/themes/garden-assets.ts`; `tests/unit/garden-manifest.test.ts` checks that map against this folder and that every file is byte-identical to the workspace export.
- Never edit these files. Fix art in the Blender scripts, re-run `export_layers.py`, then copy `export/garden_manifest.json` and `export/1536/*.png` here again (and run the tests). A later art revision raises `CURRENT_THEME_VERSIONS.garden` once a release could have stored version 1 (ASSET_SPEC).
