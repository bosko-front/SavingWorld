# Garden world — Blender source workspace

Source art for the Pro **Garden** theme (docs/ASSET_SPEC.md, PRODUCT_REQUIREMENTS R11). This folder holds the editable Blender scene and the scripts that generate it. It is **not** read by the app: approved exports go to `assets/themes/garden/` in Phase 17, with a manifest, exactly like the Island (D76, D77).

Status (26 October 2026): **art complete and closed — `export/` is the approved visual baseline for Phase 17 (D124).** The owner approved all eleven states, the layer export (Step 4, D120) and the visual polish pass (D123, art version 1 kept), then closed the workstream (D124): butterflies from 30%, petals from 40%; water, koi, butterflies, petals and the lantern/greenhouse glows are integrated in Phase 17 where feasible with the existing React Native renderer; flower swaying, canopy-only movement and butterfly wing animation are not required for the MVP. Phase 17 ([PHASE_17](../../../docs/prompts/PHASE_17.md), Step 5 of the brief) copies `export/` to `assets/themes/garden/` unchanged. Any later art change is a new owner-approved revision.

## Reuse of the Island pipeline

The Garden is generated by its own package, `scripts/swg/`, which imports the Island's shared modules from `assets/worlds/island/scripts/swi/` read-only (nothing in the Island folder changes):

| Island module | Used for |
| --- | --- |
| `swi/rig.py` | The **same frozen rig**: orthographic camera 57°/0°/45°, ortho scale 35.2, 2048×1536 (4:3), sun, fill, bounce, sky, Cycles/AgX settings. Both worlds share projection, light and shadows (ASSET_SPEC "Match camera angle, lighting… across both themes"). |
| `swi/stylize.py` | The approved storybook pass (light bands, soft Freestyle outlines, Kuwahara), via `rig.configure_render` |
| `swi/materials.py` | Painted, terrain, rock, wood, foliage, water (Flow UV), waterfall, cloud and emissive shaders |
| `swi/common.py` | `Geo` primitives, metaball merging, seeded noise, colors |
| `swi/nature.py`, `swi/terrain.py`, `swi/props.py` | Generic builders: broadleaf/pine trees, bushes, flowers, cloud shapes, stone stacks, grass tufts, foam, floating islets |
| `swi/preview.py` | Backdrop composite, phone-size copies, contact sheets |

Garden-specific code lives in `scripts/swg/`: `layout.py` (every position, single source of truth, in screen-plan coordinates `(v, u)`), `terrain.py`, `water.py`, `plants.py`, `structures.py`, `stages.py`, `style.py` (no-outline marks).

## Layout

| Path | What it is |
| --- | --- |
| `reference/garden-reference.webp` | The owner's visual reference (direction only; nothing traced, sampled or embedded) |
| `scripts/build_garden.py` | Rebuilds the whole scene from scratch and saves `source/garden.blend` (`SW_ONLY_STAGES=0,6` builds a subset) |
| `scripts/render_preview.py` | High-quality render of one stage (2048×1536, 256 samples) plus backdrop and phone-size copies; `-- 10 256 <dir> 1` also shows the ambient-only butterflies |
| `scripts/draft_render.py` | Fast low-sample render for iteration |
| `scripts/check_framing.py` | Reports whether a stage stays inside the shared frozen camera frame |
| `scripts/verify_stages.py` | Per-stage checks (as the Island's): identical camera/lights/render settings/terrain fingerprint, add-only stages, no floating pieces |
| `scripts/render_ambient.py` | Inputs for the ambient layers (`renders/ambient/`): stage 0 without the drifting clouds, stage 6 without the koi, the butterflies alone, flat ID masks (clouds, koi, trees, lights) and the 16-bit water flow pass |
| `scripts/export_layers.py` | Exports the eleven approved renders as stacked layers plus `export/garden_manifest.json`, checks the rebuild against every render and writes the review sheets (uses the Island export's helper half read-only) |
| `export/` | Phase 17 input: `2048/` and `1536/` layer PNGs, `garden_manifest.json`, `garden_layers_review.png`, `garden_ambient_review.png` |
| `scripts/milestone_report.py` | Pixel checks between rendered stages (visible change per step, unchanged rock underside band, one resolution) and the side-by-side sheet `renders/milestones/garden_milestones.png` |
| `source/garden.blend` | Editable scene (generated, compressed) |
| `renders/review/` | The approved Step 2 review render (100%, butterflies shown) and the reference comparison (committed) |
| `renders/milestones/` | Milestone renders: one transparent 2048×1536 master per rendered stage (without ambient-only elements) and `garden_milestones.png`; backdrop and phone-size copies are made locally and not committed |
| `renders/preview/` | Ad-hoc renders (not committed) |

## Rebuild and render

Blender 5.2.3 LTS (`/Applications/Blender.app`), Cycles on the Apple M4 GPU (Metal).

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P assets/worlds/garden/scripts/build_garden.py
```

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b assets/worlds/garden/source/garden.blend -P assets/worlds/garden/scripts/render_preview.py -- 10 256 renders/review 1
```

The build is deterministic (seeded random numbers, fixed noise offsets). Edit the scripts, not the `.blend`.

## Composition

A rounder floating garden than the Island's squarish rock, on three lawn terraces held by **dry-stone retaining walls** (the Garden's signature: a cultivated, terraced garden rather than a wild island). Screen-plan positions (`v` right, `u` into the picture):

- **Back terrace:** the glass **greenhouse** (hero, door facing the path, plants and warm lights inside, planters in front), raised **vegetable beds** with a wooden fence on the left, a white **picket fence** on the right, the stone **fountain**, and the pink **blossom tree**.
- **Middle terrace:** the **seedling plot** (left), the **flower bed** (center), the **rill** coming down from the fountain, and the **rose pergola** with a bench and a hanging lantern (right).
- **Front terrace:** the **lily pond** with koi, fed by a cascade over the front wall; its outflow **stream** runs under the wooden **bridge** and leaves over the front-left lip as the **waterfall**; a bench by the pond, a birdbath, the seating **nook** (left).
- **Main path:** paved with cream flagstones from the front edge up two flights of stone stairs (through gaps in the walls) to the greenhouse door, with four lanterns.
- **Edges and underside:** rim shrubs and flowering bushes, trees around the back and sides, ivy on the walls, flowering vines hanging over the warm rock underside, three floating islets, three clouds (one catches the waterfall).

## Animation readiness (planned in Step 1; final scope in D124)

Separate objects were planned from the start so the export can cut ambient layers without masks where possible:

| Ambient element | Objects | Planned motion (existing Reanimated ambient system, D90-D93) |
| --- | --- | --- |
| Trees | `Tree_<name>_Trunk` + `Tree_<name>_Canopy` per tree (13 trees incl. the blossom tree); trunk base = sway pivot | Canopy-only sway (trunk stays), like the Island's per-tree `sway` |
| Water | `Water_Rill`, `Water_Stream`, `Water_Pond`, `Water_Fountain`, `Waterfall`, `Water_FountainCurtain` with the Island's Flow UV | Three flow layers per the Island's D93 method (streaks travel along the flow; no blinking opacity on the whole surface) |
| Koi | `Koi_1`, `Koi_2` | Slow looping glide in the pond |
| Butterflies | `Butterfly_1..3` in `SWG_Ambient` | Occasional short flight, one at a time |
| Lanterns | `Lantern_Glow_1..4`, `Lantern_Glow_Pergola`, `Greenhouse_LightGlow` | Very subtle warm glow change |
| Clouds | `Cloud_1..3` | Drift, as on the Island |
| Falling petals | from the blossom tree (three export-only petal sprites) | Occasional single petal |

Every ambient value must rest at 0 so the still stack equals the approved picture (as for the Island), run only on a visible Home with the app active, stop under Reduce Motion, and be measured on a physical iPhone in Phase 21.
